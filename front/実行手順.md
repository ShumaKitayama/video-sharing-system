# フロントエンド Docker 実行手順

この文書は、**コマンドを上から順にコピーして実行するだけ**でフロントエンドを起動するための手順書です。

- バックエンドやデータベースの準備は不要です（Vercel 上の API を使います）
- Node.js や npm のインストールも不要です（Docker の中に入っています）
- `docker compose` は使いません
- 使うコマンドは `docker` だけです

仕組みやトラブルの詳細は [`DOCKER.md`](./DOCKER.md) を見てください。

---

## 事前確認（最初の1回だけ）

### 1. Docker Desktop を起動する

Mac なら Dock や Launchpad から **Docker** を起動します。  
メニューバーにクジラのアイコンが出ていれば OK です。

### 2. ターミナルで確認する

ターミナルを開き、次を実行します。

```bash
docker version
```

エラーが出なければ準備完了です。  
`Cannot connect to the Docker daemon` と出たら、Docker Desktop がまだ起動していません。

## Windows で起動する（推奨）

Windows では長い `docker run` コマンドを入力しません。
Node.js や npm もインストール不要です。

### PowerShell で起動する

すでに `front` フォルダを開いている場合は、次の1行だけ実行します。

```powershell
.\docker-start-windows.cmd
```

リポジトリ直下（`video-sharing-system`）にいる場合は、次を実行します。

```powershell
.\front\docker-start-windows.cmd
```

このファイルが自動で次の処理を行います。

1. Docker Desktop が起動しているか確認
2. フロントエンドのイメージをビルド
3. Windows のフォルダを安全な `--mount` 形式で接続
4. `http://localhost:5173` でフロントエンドを起動

エクスプローラーで `front\docker-start-windows.cmd` をダブルクリックしても起動できます。

> `.cmd` を使うため、PowerShell の実行ポリシー設定は不要です。

### 止める

起動中の画面で `Ctrl + C` を押します。

## macOS / Linux で起動する

### 手順 1: `front` フォルダへ移動する

このリポジトリの `front` フォルダに移動します。

```bash
cd front
```

> パスが分からないとき: ターミナルに `cd ` と入力したあと、Finder から `front` フォルダをドラッグ＆ドロップするとパスが入ります。

### 手順 2: イメージを作る（初回だけ）

次のコマンドを実行します。初回は 1〜3 分かかることがあります。

```bash
docker build -f Dockerfile.dev -t video-front-dev .
```

成功すると、最後のほうに次のような表示が出ます。

```txt
Successfully tagged video-front-dev:latest
```

> **2回目以降**は、`package.json` や `Dockerfile.dev` を変えていなければこの手順は省略して大丈夫です。

### 手順 3: 起動する

```bash
docker run --rm -it -p 5173:5173 -v "$(pwd):/app" -v /app/node_modules video-front-dev
```

> **注意:** `-v "$(pwd):/app"` のように、コロン（`:`）も含めてダブルクォートで囲みます。
> `-v "$PWD":/app` と書くと環境によって引数がずれ、`docker: invalid reference format` になります。

各オプションの意味（覚えていなくて大丈夫です）:

| オプション | 意味 |
| --- | --- |
| `--rm` | 止めたらコンテナを自動で消す |
| `-it` | キーボード入力（`Ctrl + C`）を受け取る |
| `-p 5173:5173` | ブラウザから `localhost:5173` で開けるようにする |
| `-v "$(pwd):/app"` | いまのフォルダをコンテナに見せる（編集がすぐ反映される） |
| `-v /app/node_modules` | ホスト側の `node_modules` で上書きされないようにする |

成功すると、次のような表示が出ます。

```txt
  VITE v8.x.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: http://172.x.x.x:5173/
```

### 手順 4: ブラウザで開く

ブラウザのアドレス欄に次を入力して開きます。

```txt
http://localhost:5173
```

> `Network:` に出る `172.〜` のアドレスは使わないでください。必ず `localhost:5173` を開きます。

動画の一覧が表示されれば成功です。

### 手順 5: 止めるとき

起動したターミナルで次を押します。

```txt
Ctrl + C
```

コンテナは自動で消えます（`--rm` を付けているため）。

## コードを編集する

1. `front/src/components/student/` や `front/src/styles/` のファイルを編集する
2. 保存する（`Cmd + S`）
3. ブラウザが自動で更新される（コンテナの再起動は不要）

編集してよい場所:

| 場所 | 内容 |
| --- | --- |
| `front/src/components/student/` | 見た目のコンポーネント |
| `front/src/styles/` | 色や CSS |

## よくある失敗と対処

| 症状 | やること |
| --- | --- |
| Windows で `docker: invalid reference format` | macOS/Linux 用コマンドを実行しているか、空白が崩れている。長いコマンドは使わず `.\docker-start-windows.cmd` を実行する |
| `docker run requires at least 1 argument` | オプション間の空白やイメージ名が崩れている。Windows では `.\docker-start-windows.cmd` を使う |
| `Cannot connect to the Docker daemon` | Docker Desktop を起動してから、もう一度コマンドを実行する |
| `port is already allocated` | すでにこのコンテナや別の開発サーバーが動いていないか確認し、止めてからやり直す |
| ブラウザが真っ白 | URL が `http://localhost:5173` になっているか確認する（`172.〜` は使わない） |
| 保存しても画面が変わらない | 編集した場所が `front/src/` の中か確認する。設定ファイルを変えた場合は `Ctrl + C` → 手順 2 → 手順 3 |
| ビルドがずっと止まっている | Docker Desktop を再起動する。それでもダメなら下の応急処置を使う |

### 応急処置（ビルドが固まって進まないとき）

```bash
mkdir -p /tmp/docker-nocreds && echo '{}' > /tmp/docker-nocreds/config.json
DOCKER_CONFIG=/tmp/docker-nocreds docker build -f Dockerfile.dev -t video-front-dev .
docker run --rm -it -p 5173:5173 -v "$(pwd):/app" -v /app/node_modules video-front-dev
```
