# 体験会手順（ブラウザだけで実施する）

生徒の端末には**何もインストールしません**。Chrome で URL を開くだけで、
穴埋め形式のステップ → 自由改造 → 動画投稿・見せ合い までを体験できます。

- 対象端末: Windows + Google Chrome
- 生徒が開く URL: `https://<フロントのURL>/lab`
- 生徒のコードは**その端末のブラウザの中だけ**で動きます（他の生徒やサーバーには影響しません）
- 動画・コメント・いいねは共通のサーバーに保存されるので、クラス全員で見せ合えます

---

## 1. 事前準備（先生）

### 1-1. サイトが動いているか確認する

1. 先生の PC の Chrome で `https://<フロントのURL>/` を開き、動画一覧が出ることを確認する
2. `https://<フロントのURL>/lab` を開き、右側にサイトのプレビューが出ることを確認する
3. 学校の端末 1 台で同じ確認をする（フィルタでブロックされていないか）

> 動画一覧が「見つかりません」のままでエラーが出る場合は、バックエンド（Vercel の API）が
> 止まっていないか確認してください。`https://<フロントのURL>/health` を開いて `"status":"ok"` が出れば正常です。

### 1-2. 生徒のアカウントを作る

1. `https://<フロントのURL>/register` を開く
2. ユーザー名・表示名・パスワードを入れて登録する（人数分くり返す）
3. 作ったアカウントをメモに書いて、各机に置く

> 当日その場で生徒が `/register` から作ることもできます。

### 1-3. 動画をいくつか投稿しておく（おすすめ）

一覧が空だとステップの変化（「NEW」や「♡ 3」など）が見えにくいので、
先生のアカウントで 2〜3 本投稿しておくと説明しやすくなります。

---

### 1-4. 動画の容量に気をつける（無料プランの上限）

動画は Vercel Blob の**無料枠**に保存しています。上限を超えると料金はかかりませんが、
**Blob が 30 日間使えなくなり、動画の投稿も再生もできなくなります。**

| 無料枠（月） | 内容 | 目安 |
| --- | --- | --- |
| 保存容量 1GB | 投稿された動画の合計 | 15 秒・720p（約 5〜10MB）なら 100 本くらい |
| 転送量 10GB | 動画を見た分の合計 | 10MB の動画なら約 1,000 回分 |

- アップロードは **1 本 30MB まで**（サイトで制限済み）
- 体験会のあとは、不要な動画を先生アカウントで削除しておく（削除すると Blob からも消える）
- 使用量は Vercel ダッシュボード → **Usage**（または Storage → `video-sharing-uploads`）で確認できる。
  80% を超えたら、その日の投稿・視聴をひかえる

## 2. 当日の流れ（目安 60〜90 分）

| 時間 | 内容 |
| --- | --- |
| 5 分 | Chrome で `/lab` を開く。右のプレビューの「ログイン」から、机のメモのアカウントでログイン |
| 30〜40 分 | STEP 1〜5（穴埋め）。左のコードの穴をクリック → 下で答えを選ぶ → 「答え合わせ」 |
| 20〜30 分 | STEP 6 → 「自由改造」。ファイル全体を書きかえて、自分だけのサイトにする |
| 10〜15 分 | 動画を撮って投稿 → 友達のプレビューで見せ合う |

### 撮影のルール（生徒に伝える）

- **長さは 10〜15 秒**まで
- スマホのカメラ設定は **720p（HD）・30fps** にする（4K や 60fps は容量が数倍になる）
- 30MB をこえると「ファイルサイズは30MB以下にしてください」と出る → 短く撮り直す

### 各ステップの内容

| STEP | 内容 | 学ぶこと |
| --- | --- | --- |
| 1 | サイトの色を変える（`index.css`） | CSS 変数で全体の色が決まる |
| 2 | 「回視聴」の言葉を変える（`VideoCard.tsx`） | JSX の「文字」と `{ データ }` |
| 3 | 100 回未満なら「NEW」と出す if 文 | 条件分岐（`<` と `>=`） |
| 4 | サムネイルにバッジを付ける | `{video.like_count}` でデータを表示 |
| 5 | コメントの名前に「さん」を付ける（`CommentItem.tsx`） | 部品（コンポーネント）の再利用 |
| 6 | 自由改造 | ここまでの応用 |

ステップの中身は `src/lab/lessons/steps.ts` で変えられます（書き方は [`src/lab/README.md`](./src/lab/README.md)）。

## 3. 画面の使い方（生徒に説明すること）

- **左**: やること・コード・答えを入れる場所
- **右**: サイトのプレビュー（自分のコードで表示されている本物のサイト）
- 上の **①〜⑥** で好きなステップに移動できる。クリアしたステップは色がつく
- **「⛶ プレビューを大きく」** で右側を広く表示できる
- **「自由改造」** タブでは、ファイルを選んで自由に書きかえられる。数秒待つか「▶ 実行」で反映
- コードがまちがっていても**サイトは壊れません**。赤いエラーが出て、そのファイルだけ元のコードで表示されます
- 「↺ このファイルを元に戻す」「↺ 最初から」でいつでもやり直せる

## 4. よくあるトラブル

| 症状 | やること |
| --- | --- |
| プレビューが真っ白・固まった | `F5` で再読み込み。止まる原因のコードがあった場合は自動で元のサイトに戻り、黄色い帯が出るので、コードを直して「もう一度ためす」 |
| Chrome が「ページが応答しません」と出す | 「ページを終了」→ `F5`。上と同じく自動で元に戻る（`while (true)` などの無限ループが原因） |
| 赤いエラーが消えない | エラーに書かれた「ファイル名・行目」を見直す。わからなければ「↺ このファイルを元に戻す」 |
| 「部品の中で通信は書けません」と出る | `fetch` などの通信は禁止にしている。データは部品に渡される `video` などを使う |
| ログインできない | 机のメモのユーザー名・パスワードを確認。プレビューの中の「ログイン」から入る |
| 「ファイルサイズは30MB以下に」と出る | 動画が長い／画質が高すぎる。10〜15 秒・720p で撮り直す |
| 動画が急に再生できなくなった | Blob の無料枠を超えた可能性。Vercel ダッシュボードの Usage を確認する（超えると 30 日間使えない） |
| 進み具合を最初からにしたい | 右上の「↺ 最初から」 |
| 別の端末に移った | 進み具合は端末（ブラウザ）ごとに保存されるため、最初からになる。動画やコメントはサーバーにあるので消えない |

## 5. 仕組み（先生・開発者向け）

```
/lab（左: ステップ・エディタ）  ──コード──▶  iframe（右: 本物のサイト）
                                          ブラウザ内で TSX を変換（Sucrase）して
                                          生徒の部品だけを差し替える
                                                   │
                                                   ▼ いつもの hooks / services
                                          Vercel の API（動画・コメント・いいね）
```

- 差し替えるのは `components/student/` の 5 ファイルと `styles/index.css` だけ
- 生徒のコードはブラウザの `localStorage` に保存される（サーバーには送らない）
- ローカルで開発したい場合は従来どおり [`実行手順.md`](./実行手順.md)（Docker）や `npm run dev` が使える
